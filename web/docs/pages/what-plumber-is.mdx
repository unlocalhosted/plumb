React Plumber finds where a React app on Tailwind v4 or plain CSS drifts from its design system, and lets you fix it from the page. It compiles your classes, stylesheets, `@apply` and inline styles with your own Tailwind, then judges the CSS that comes out against your tokens.

For spacing, radius and type, a value is on your tokens when it equals one of them exactly. If your spacing tokens are 8px and 16px, `gap-[13px]` is off, and Plumber offers both.

## What it judges

Plumber judges values in seven families:

| Family | For example |
| --- | --- |
| <Family id="spacing">Spacing</Family> | `gap`, `padding`, `margin`, `inset` |
| <Family id="colour">Colour</Family> | text, backgrounds, borders, fills |
| <Family id="radius">Radius</Family> | border radius |
| <Family id="type">Type</Family> | font size, weight, line height, letter spacing |
| <Family id="motion">Motion</Family> | durations and easing |
| <Family id="elevation">Elevation</Family> | shadows |
| <Family id="z">Z-index</Family> | stacking |

It also checks **habits** your team writes down (such as "hover styles only apply on devices that can hover"), **overrides** that restyle a design-system component from outside, and **imitations**, which are hand-built copies of a component you already have. On the running page it checks [craft, accessibility, wording and behaviour](/docs/what-plumber-checks).

## What it compares with

It compares values with the tokens in your theme. When a value is off, Plumber names the tokens that fit, along with the reasons written beside them, so you can choose by meaning as well as by distance.

<Callout kind="note" title="Tailwind’s defaults">
If your theme defines its own tokens for a family, Plumber reports Tailwind’s built-in values in that family as drift, because your team didn’t choose them.
</Callout>

## What happens next

- **In your terminal**, `npx plumber check` reports what is wrong, why it matters and what to do. It doesn’t edit your code.
- **On your page**, the overlay shows what any element is made of and writes the fix you pick to the source file.
- **In CI**, a ledger records the drift you already have and any exceptions you accept with a reason, so that only new drift fails a pull request.

<Callout kind="why" title="Why it compiles first">
The same value can be written as a class, in a stylesheet, through `@apply` or as an inline style. A rule about class names would miss the last three and misread classes that compile to something else, so Plumber judges the CSS they compile to.
</Callout>
