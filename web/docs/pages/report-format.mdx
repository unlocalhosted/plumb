`plumber check --json` prints one report with what was read, every finding, coverage per family and the state of the ledger.

```sh
npx plumber check --json > plumber-report.json
```

The [report schema](https://github.com/unlocalhosted/plumb/blob/main/schema/report.schema.json) describes every field, and ships in the package as `schema/report.schema.json`. [Findings](/docs/findings) explains the fields you will read most.
