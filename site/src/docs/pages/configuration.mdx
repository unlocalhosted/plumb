Every option `plumb.config.ts` (or `.mjs`, `.js`) accepts, read from Plumb's config schema. Most projects need only `decisions` and `habits`; `plumb init` writes a starting config for you.

```ts
// plumb.config.ts
export default {
  decisions: { spacing: { from: ['theme:--spacing-*'] } },
  habits: ['hover-gate', 'focus-outline', 'transition-named', 'no-ease-in'],
}
```
