React Plumber · twelve logo approaches

Brief: React Plumber, playful but crafted, in the spirit of Raycast, Arc and Figma/Framer. Twelve different ways a logo could work (lettering, built symbols, a seal, a mascot), each from the name or the job. Sketches to narrow from, not finished marks.

1Built P

A P assembled from simple coloured parts (stem, bowl, a block set beside it), the way Figma's mark is built. Plumber puts parts in place.

2Folded P

A P folded from one ribbon, its turns in a darker tone, like Raycast's and Framer's faceted marks. Crisp, ownable, works alone as an app icon.

4Pl, one stroke
