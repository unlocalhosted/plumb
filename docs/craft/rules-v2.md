# Craft rules v2: above the bar

The tacit rules that sit beside v1 ([rules.md](rules.md)). v1 holds what a great mentor says out loud; v2 holds what is learned from platform code, library maintainers and Apple, and is rarely said. Numbers continue from v1, which ends at 77, so a number means one rule across both documents. Rules that change or sharpen a v1 rule are listed first, under Amendments, and are not repeated below.

**Bar:** `tacit` = above the bar: rarely said, to be referenced in the list and written up in documentation. `known` = obvious or widely circulated, kept so React Plumber can build it in. Nothing was pruned: weak and well-known findings are rows too.

**Detect:** ✓ measurable on the rendered page or by driving it · ~ partly / needs a probe or device · ✗ taste, not checked.

Status: catalogue, 2026-11-05. Sources: crafting-ui docs/research/tacit/
