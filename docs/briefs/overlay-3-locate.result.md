# Overlay layer 3 result

Implemented `overlay/src/locate.js` and the dev-client API `window.__plumb = { locate, site }`. Location results contain project-relative `file`, one-based opening-`<` `line`/`column`, nearest owner `component`, DOM `tag`, and `via` (`data-plumb-source`, `react19`, or `react-debugSource`). Explicit metadata wins; React 19 uses the first non-runtime `_debugStack` frame and its source map; React 17/18 uses `_debugSource`. Unsupported or unresolvable elements return `null`. Imperative children cannot borrow a parent's fiber location.

Added dependency-free source-map loading and VLQ decoding, with inline base64/percent-encoded data, relative map URLs, `sourceRoot`, unmapped segments, nested index-map sections (including section URLs), and per-script caching. Webpack virtual modules are recovered by JSON-decoding their eval strings, including Next's Trusted Types wrapper; fetched JavaScript is never executed. Position handling follows the [source-map specification](https://tc39.es/source-map/).

Added authenticated `GET /__plumb/resolve?source=…` to the shared HTTP/Web handler. Session membership and realpath checks refuse outside-root sources, `node_modules`, untracked files, and escaping symlinks. Supported spellings include webpack URLs, `/@fs/`, file URLs, project-relative paths and `/src`/`/app` browser paths. Optional `line` and `column` are validated and corrected to the authored JSX opening tag using the server AST. `site` requests at that opening tag include only its attributes, including multiline class/style declarations; same-line siblings and descendants stay separate. Existing token-column and line-only queries retain their selection semantics. Warm source changes and deletions reconcile before resolving.

All hosts serve the ES module graph using the existing public-module origin/CORS policy; API calls retain the existing token policy. Package contents include the new browser modules. No overlay UI or browser build step was added. React 18 browser fixtures use an isolated local dev fixture dependency, avoiding peer conflicts with the repo's React 19 installation.

## Astra review fixes — 2026-10-10

1. **Fixed: runtime filtering and host identity.** Stack frames are parsed before classification. Runtime classification uses package/module paths, including mapped paths for opaque Next chunks, rather than substrings in authored filenames or component names. An unmappable first authored frame refuses instead of borrowing its caller. Resolve validates the expected host tag before correcting an anchor. Regression: `react-dom-helper.jsx` renders a span through a section's `children={renderLeaf()}` expression; browser assertions require the helper's span and its declarations. The HTTP integration also refuses resolving a span to the section anchor.

2. **Fixed: stale source maps after HMR.** Vite's transformed HTML module subscribes through `import.meta.hot` to `vite:afterUpdate`; its overlay import is explicitly external to Vite's import analysis. Next uses a module-version query against the server's reconciled source hash. Authored map `sourcesContent` is SHA-256-bound to that source; missing evidence or a hash mismatch returns null before anchor correction. Retained React stack evidence stays bound to its original source snapshot across invalidation. Script text, map data, decoded entries, virtual-module indexes and failures invalidate together; caches are capped at 64 entries with a 60-second lifetime, and failed loads can retry. Regression: stable script/external-map URLs, temporary 404 recovery, a valid but obsolete div coordinate, changed source hashes and mappings, the transformed Vite HMR hook, and live Vite/Next HMR browser assertions.

3. **Fixed: nested JSX in props belongs to its own element.** A snapshot-cached AST ownership table selects the nearest containing JSX opening element. Parent requests exclude declarations in nested prop JSX, ordinary descendants and siblings. Regression: `children={<span className="gap-[43px]" />}` inside a div with `py-[10px]`; HTTP and browser assertions require each element's own declarations. Forwarded values still cannot borrow caller declarations.

4. **Fixed: opening anchors retrieve edit choices.** Site and column-scoped edits share the ownership selector; exact-token and line-only queries retain their behavior. Regression: browser feature slices in all four hosts locate an element, read its site, retrieve multiline attribute choices, apply a returned id/hash, and verify the source changed. The same opening-anchor/site/edits/apply/source-change slice also passes through real HTTP independently of browser availability.

5. **Fixed: bounded, watcher-independent target reconciliation.** Resolve/site/edits/apply stat the named target, its containing directory and retained analysis inputs: configuration/imports, preset/DTCG inputs (including known empty matches and missing literal inputs), compiler/theme/stylesheet and custom-property producers, and import consumers/producers. Shared stylesheets remain dependencies because they affect class existence and imitation. Dependency metadata updates affected files and their relationships rather than rebuilding the project on each local edit. Unchanged resolve reuses source text and AST ownership. Events never establish freshness or widen a target request. Report/decisions retain full stat reconciliation; new unrelated inventory/glob members are discovered by full reconciliation, while known paths and the requested target are checked immediately without watchers. Regression: 240 unrelated sources, fewer than 20 stats for unchanged resolve/site/edits and fewer than 64 for apply including repeated reconciliation and existing anti-alias checks; no unrelated file is statted. Additional watch-disabled checks cover source creation/deletion, producer edits, config imports, theme changes, presets and previously empty DTCG glob inputs against fresh sessions. Existing watch-disabled parity tests still pass.

6. **Fixed: source-map preparation and lookup cost.** Browser parsing, eval-module indexing, hashing and VLQ decoding run in a plain module worker. Virtual modules are indexed once per chunk cache version; index sections load only when selected, rows decode lazily with retained delta checkpoints, and section/column lookup uses binary search. Decoding/indexing yields in bounded slices; newer pointer requests and HMR cancel obsolete work. Cache bounds/version invalidation apply to these indexes too. HTTP regressions require an unrelated 300,000-segment section to remain unfetched and an unrequested malformed row to remain undecoded. Both real Next browser fixtures now include a 4,000-element client page and a measured CDP renderer `TaskDuration` assertion: each of five warm locate samples must consume less than 16 ms on the main thread. This timing assertion was added but could not be executed in this environment; no measured passing timing is claimed.
