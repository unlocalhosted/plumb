Section 1 · “Keep AI slop out of your app” · three comps

A After every edit: the agent writes slop, the hook catches it, the agent fixes it

Guardrails for agents

Your agent writes the UI. Plumber keeps it yours.

After every edit, Plumber checks what changed against your theme. Every hardcoded value comes back with the exact fix, so the agent corrects itself before you ever see it.

  • Runs on every editA hook in Claude Code or Cursor, set up by plumber install --hooks.
  • Exact fixes, not adviceThe file, the line, the class to write.
  • Only what’s newToday’s debt is recorded once and left alone.
